Walkthroughs that go beyond the quick start: full deployment guides and ready-to-use templates for common stacks.

- [Example Local Deployment](example-local-deployment/): A single-server deployment with Docker or Podman, including DNS
- [Example Templates](example-templates/): Ready-to-use templates — Ubuntu, PHP, MariaDB, Valkey, and a full Ubuntu desktop

Each tutorial is self-contained; start with whichever matches the infrastructure you already have.
